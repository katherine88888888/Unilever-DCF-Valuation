# Unilever-DCF-Valuation
## Overview
This project builds a Discounted Cash Flow (DCF) valuation model for Unilever.  
The model incorporates historical financials, forecasts, intrinsic valuation, and a sensitivity analysis.  
It was developed in Microsoft Excel as part of my finance learning portfolio.

## Key Features
- **Historical Data (2019–2023):** Collected and structured revenue, EBIT, D&A, CapEx, and working capital changes.  
- **Forecast (5 Years):** Projected revenue growth, EBIT margins, and capital expenditures to estimate Free Cash Flow (FCF).  
- **DCF Valuation:** Discounted forecasted FCFs to present value using WACC, and calculated terminal value with perpetual growth.  
- **Sensitivity Analysis:** Tested different assumptions for WACC (5–11%) and terminal growth (0–3%) to assess intrinsic share price robustness.  

## Result
- **Base case assumptions:** WACC = 7.41%, Terminal growth = 1.00%  
- **Intrinsic share price:** €57.46
- **Market price (as of Sept 2025):** €53.62 
- **Valuation insight:** Model suggests Unilever is overvalued by ~7% under base case assumptions.  
- **Sensitivity range:** Intrinsic value varies between €33.76 - €95.99  depending on WACC (5–7%) and terminal growth (0–2%).
